<h1 align="center">MLab 2.3.2</h1>

<p align="center">
  Transmissão de tela para aula ao vivo na rede local: o professor compartilha a tela pelo app,
  e os alunos assistem no navegador, sem instalar nada.
</p>

A 2.3.2 é uma versão de manutenção. O app funciona exatamente como na 2.3.1: a mudança está nos pacotes Linux
anunciados e na documentação, que passam a corresponder ao que a release de fato traz.

## Destaques

- **Pacotes Linux sem promessa vazia.** O MLab anunciava um pacote Linux `.tar.gz` que nunca chegava às releases. Ele
  sai da configuração de build e da documentação: no Linux, o MLab é distribuído em **AppImage**, que roda em qualquer
  distribuição (Fedora, Arch, openSUSE…), e em **`.deb`**, para Debian e Ubuntu.
- **Instruções de desenvolvimento em dia.** O README passa a pedir o **Go 1.26.11**, a versão exigida pelo projeto
  desde a correção da queda do servidor no Windows, e o link de instalação no Linux aponta para ela.

## Downloads

| Sistema | Arquivo |
| --- | --- |
| Windows 10/11 | `MLab-Setup-2.3.2.exe` |
| macOS | `MLab-Mac-2.3.2.dmg` (ou `.zip`) |
| Linux | `MLab-Linux-2.3.2.AppImage` (qualquer distribuição) ou `.deb` (Debian/Ubuntu) |

Os alunos não instalam nada: basta abrir no navegador o link que o professor compartilha. As instruções de instalação
de cada sistema estão no [README](https://github.com/MateusARJ/MLAB#instala%C3%A7%C3%A3o-para-uso-professor).

> **Atualizando da 2.3.1?** Não é obrigatório: o funcionamento é o mesmo. Só o app do professor muda.

## Novidades por versão

### 2.3.2
- O pacote Linux `.tar.gz`, anunciado mas nunca gerado, sai da configuração do instalador, do envio da release e da
  documentação. O README indica o AppImage para distribuições sem `.deb`
  ([#169](https://github.com/MateusARJ/MLAB/issues/169), [#174](https://github.com/MateusARJ/MLAB/pull/174)).
- O README pede o Go 1.26.11 para desenvolver o MLab, no lugar do Go 1.26.0.

O histórico completo do MLab, versão por versão, está nas notas da
[2.3.1](https://github.com/MateusARJ/MLAB/releases/tag/v2.3.1).

## Limitações conhecidas

- A edição **MLab HTTPS** não tem instalador publicado no momento; ela volta numa próxima atualização.
- Depois de uma retomada do servidor, o aluno precisa abrir o link de novo e informar nome e matrícula. A volta
  automática do aluno à transmissão está em análise.
- No Linux com XWayland, a presença do cursor na transmissão pode congelar quando o ponteiro está fora de janelas X11
  ([#140](https://github.com/MateusARJ/MLAB/issues/140)).
- Alguns navegadores avisam que o download é inseguro porque a página da rede local é servida em `http`
  ([#47](https://github.com/MateusARJ/MLAB/issues/47)); basta confirmar o download.
- O macOS não é assinado nem notarizado: na primeira abertura, use **botão direito → Abrir**.
