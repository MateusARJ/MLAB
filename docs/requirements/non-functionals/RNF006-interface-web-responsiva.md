#  RNF006 — Interface Web Responsiva

> **Categoria:** Usabilidade
> **Meta / Alvo:** `Desktop e Mobile`
> **Status:**  Aprovado

---

##  Descrição do Requisito

O player do aluno deve ser totalmente responsivo (desktop-first >= 1280px e mobile funcional < 768px).

---

##  Justificativa e Critério de Medição

Permitir que os alunos assistam às aulas tanto em notebooks quanto em tablets ou smartphones.
