# 🛡️ RNF017 — Sanitização XSS no Chat de Texto

> **Categoria:** Segurança Web  
> **Meta / Alvo:** `Sanitização 100%`  
> **Status:** 🟢 Aprovado  

---

## 📌 Descrição do Requisito

Todas as mensagens enviadas no chat devem sofrer sanitização estrita contra Cross-Site Scripting (XSS) e HTML Injection.

---

## 🎯 Justificativa e Critério de Medição

Impedir a execução de scripts maliciosos nos navegadores dos alunos ou no aplicativo do professor.
