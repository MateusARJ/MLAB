# 🛡️ RNF015 — Processamento Eficiente de CPU no Backend

> **Categoria:** Desempenho  
> **Meta / Alvo:** `Uso de CPU < 15%`  
> **Status:** 🟢 Aprovado  

---

## 📌 Descrição do Requisito

O encaminhamento de pacotes RTP no backend deve ser feito estritamente em memória sem recodificação de mídia, mantendo o uso de CPU baixo.

---

## 🎯 Justificativa e Critério de Medição

Maximizar a eficiência de custo de infraestrutura permitindo rodar o servidor em instâncias modestas de nuvem.
