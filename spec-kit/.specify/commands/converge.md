# /speckit.converge

Compare implementação real com spec/plan/tasks.

Registre:
- requisitos atendidos;
- requisitos parcialmente atendidos;
- divergências;
- testes faltantes;
- novos tasks necessários;
- impacto de versão (MAJOR, MINOR, PATCH ou nenhum) com justificativa pelo escopo de `docs/versionamento.md` §2.

Nunca esconda gaps para produzir um PASS artificial.

Saída obrigatória: `spec-kit/specs/<feature>/converge.md` a partir de `spec-kit/.specify/templates/converge-template.md`.
